# MAYKOP VPN Test — бесплатный тест на iPhone

Один SwiftUI target, iOS 17+, iPhone. Системный IKEv2 с EAP (логин/пароль).
Нет Network Extension, Personal VPN, App Groups, Push, iCloud и платного аккаунта.
Это прототип оболочки: статус читается в системных настройках. HTTPS-проверка
сравнивает выходной IP с адресом сервера и не выдаёт себя за NEVPNStatus.
Работа на физическом iPhone подтверждается отдельно после установки.

## Сборка на Windows через GitHub

Запустить workflow в отдельном открытом репозитории, скачать артефакт MaykopTest.
В нём unsigned IPA, SHA-256 и отчёт проверки. В публичном коде нет настроек
владельца, паролей и исходников основного VPN. CI проверяет один target,
отсутствие extensions, embedded provisioning profile и entitlements.
IPA без подписи Apple ещё не устанавливается.

## Первая установка

1. На Windows установить Sideloadly с https://sideloadly.io/ и требуемые им
   официальные USB-компоненты Apple. При ошибке Anisette следовать инструкции
   Sideloadly для веб-версии iCloud; не удалять программы Apple вслепую.
2. Подключить разблокированный iPhone кабелем, подтвердить доверие.
3. Выбрать MaykopTest.ipa, свой iPhone и бесплатный Apple Account. Нажать Start.
   Пароль и код Apple вводить лично в окне программы, не присылать в чат.
4. При необходимости доверить свою подпись в Настройки → Основные → VPN и
   управление устройством. Включить Режим разработчика, если iOS запросит.
5. Открыть MAYKOP VPN Test. Настройки сервера вводятся локально. Пароль хранится
   в обычном Keychain этого приложения, без sharing.
6. Сформировать профиль. Установка профиля всегда требует ручного подтверждения
   владельца. Передача через Share Sheet не гарантирует экран установки:
   надёжный уже проверенный путь — передать профиль по доверенному USB через
   Apple MobileConfig, затем Настройки → Профиль загружен → Установить.
7. Открыть VPN в настройках, выбрать MAYKOP iOS Test, включить. Проверить трафик
   в приложении и сопоставить его с IPsec-счётчиками отдельного тестового сервера.

Установка самого IPA только с телефона этой схемой не выполняется: нужен
Windows-компьютер для подписи. После установки приложение работает на телефоне.

## Обновление подписи

Бесплатная подпись действует 7 дней. Повторить установку того же IPA тем же
Apple Account с тем же bundle ID. Автообновление Sideloadly требует доступного
компьютера и USB либо настроенной Wi-Fi-связи. Не обещаем «один клик за 2 минуты»:
Apple может запросить повторный вход или подтверждение.

Профиль VPN не привязан к 7-дневной подписи приложения, но соединение зависит
от сервера, срока сертификата и действительности учётных данных. Тестовый сервер
ограничен по времени и не является бессрочной услугой.

## Проверка профиля и подписи

Профиль — XML property list: PayloadType Configuration, внутри ровно один
com.apple.vpn.managed, VPNType IKEv2, AuthenticationMethod None,
ExtendedAuthEnabled 1, RemoteAddress/RemoteIdentifier/AuthName/AuthPassword.
Проверка синтаксиса: `plutil -lint file.mobileconfig` на macOS или Python plistlib
на Windows; дополнительно сверить ключи со схемой Apple IKEv2. Это не заменяет
установку и проверку подключения на iPhone. Профиль не подписан и содержит пароль:
не публиковать его и не отправлять посторонним.

После подписи Sideloadly проверить фактическую подпись отдельно: стандартные
application-identifier, com.apple.developer.team-identifier, keychain-access-groups
и get-task-allow возможны; никаких специальных VPN capabilities быть не должно.
Пустой отчёт unsigned IPA не доказывает права будущей подписи.

Для безопасной настройки по USB можно передать в Documents только этого
приложения файл maykop-test-config.json с configuration и password. Приложение
при открытии сохраняет пароль в Keychain и удаляет файл. Не хранить этот файл
в репозитории или общем облаке.
